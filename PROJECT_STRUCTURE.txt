## خطوات التشغيل:

1. نسخ المشروع
   git clone <repo>
   cd electrical-scraper

2. تثبيت المكتبات
   pip install -r requirements.txt

3. إضافة مفتاح API
   echo "ANTHROPIC_API_KEY=your_key_here" > .env

4. تشغيل الداشبورد
   streamlit run dashboard.py

5. فتح المتصفح
   http://localhost:8501


## الصفحات المتوفرة:

🏠 الرئيسية
   - KPI cards (المنتجات، المتاجر، المطابقة، التوفير، التوصيفات)
   - شبكة المتاجر مع عدد المنتجات
   - معاينة توصيفات الأعمال

📦 المنتجات
   - قائمة كاملة بـ البحث
   - فلاتر: المتجر، نطاق السعر
   - جداول مع horizontal scroll

📂 الفئات والتفريعات
   - تصنيف تلقائي للمنتجات
   - إحصائيات الفئات
   - تفصيل حسب المتجر

⚖️ مقارنة الأسعار
   - عرض نفس المنتج من متاجر مختلفة
   - تحديد أفضل سعر
   - حساب نسبة التوفير

🏆 أفضل العروض
   - المنتجات ذات أكبر فارق سعري
   - رسم بياني للأفضل 20 عرض

🤖 توصيف الأعمال
   - توصيفات احترافية بـ Claude AI
   - تصنيف حسب الفئة
   - نطاقات الأسعار المحسوبة

📈 تاريخ الأسعار
   - تتبع تغير السعر عبر الزمن
   - رسم بياني تفاعلي

📊 الرسوم البيانية
   - توزيع الأسعار (histogram)
   - متوسط الأسعار حسب المتجر


## ملاحظات مهمة:

⚠️ المفتاح (API Key):
   - استخدم مفتاح Anthropic من https://console.anthropic.com
   - احفظه في ملف .env (لا تشاركه!)

⚠️ الجدولة:
   - التحديث التلقائي يعمل الساعة 2 صباحاً بتوقيت الكويت
   - يمكنك التحديث اليدوي من الزر ⚙️ في الشريط الجانبي

⚠️ الويب سكريبنج:
   - قد تحتاج VPN إذا كنت في منطقة محجوبة
   - كل تحديث يأخذ وقتاً (1-2 دقيقة)

✅ الأداء:
   - البيانات تُحفظ محلياً في JSON
   - لا توجد قاعدة بيانات خارجية
   - سرعة التحميل < 1 ثانية
